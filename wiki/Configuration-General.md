# Configuration — General

**English** · [Italiano](IT-Configurazione-Generale)

*Dashboard → your server → **Generale***

The first section to touch, because everything else displays through it.

---

## Language

The language VionDefence speaks **in this server**: command replies, log embeds, DM
notices, ticket messages.

Available: **English (`en-US`)** and **Italiano (`it-IT`)**. Default is `en-US`.

This is not the same as the dashboard's language. The dashboard follows your personal
preference and can differ from every server you manage.

---

## Timezone

Used for every timestamp the bot renders — log embeds, ticket transcripts, sanction
history, expiry dates.

Set it to where your community actually is, not where you are. `Europe/Rome`,
`Europe/London`, `America/New_York` and so on.

Default is `America/New_York`, which is almost certainly not what you want.

---

## Date and time format

How those timestamps are written.

| Setting | Examples |
|---|---|
| **Date format** | `DD/MM/YYYY` → 02/09/2026 · `MM/DD/YYYY` → 09/02/2026 · `YYYY-MM-DD` → 2026-09-02 |
| **Time format** | `HH:mm:ss` → 17:55:10 (24h) · `hh:mm:ss A` → 05:55:10 PM (12h) |

Defaults are `MM/DD/YYYY` and `hh:mm:ss A`.

Pick the convention your staff reads without thinking. A moderation log is scanned
under pressure; an ambiguous `02/09` costs more than it looks.

---

## Do this now

1. Set the **language**.
2. Set the **timezone**.
3. Set **date** and **time format** to match.
4. Move on to [Logs](Configuration-Logs) — with General done, the timestamps in your
   logs will be readable from the very first entry.
